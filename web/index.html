Dashboard

Your Claude usage, across every device.

clare puts your account's official weekly usage in one place, works out which computer or browser used it, and holds a weekly budget you choose in Claude Code and on claude.ai. It also tells you when a device stops reporting or its setup changes.

Open my dashboard View on GitHub

How it works

  1. Set it up once

    scripts/setup.sh deploys clare's small backend to your own free Supabase project and its pages to GitHub Pages, then opens your dashboard.

  2. Add your devices

    In the dashboard, Add a device makes a link. On each computer it's one command for Claude Code; in each browser, the clare extension.

  3. Stay inside your budget

    Pick how much of the weekly limit to use. Claude Code hooks and the extension stop new work at the budget, or just warn if you prefer monitor-only.

What it covers

clare only enforces where it runs. Anything else still shows up in the weekly total, as unobserved usage.

Privacy

  • Only numbers and device details leave your computers: token counts, model names, times, meter percentages, device names, OS and browser.
  • Never prompts, replies, file contents or conversation titles.
  • Everything runs on accounts you own: your Supabase project and your GitHub Pages site.
